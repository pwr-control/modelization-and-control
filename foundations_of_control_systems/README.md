# Foundations of Control Systems

Control theory examples kept outside the application projects. Most of the applied control work
of this repository lives with its plant: see `foundations_of_power_electronics` (current and
voltage loops, PLLs, observers, model predictive control) and `foundations_of_mechanics`
(LQR and state feedback on torsional and distributed systems).
